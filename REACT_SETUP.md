# React + shadcn + Tailwind CSS + TypeScript Setup Guide

This file provides instructions on how to set up a React environment supporting the React components copied into `/components/ui/` (`web-gl-shader.tsx`, `liquid-glass-button.tsx`, and `demo.tsx`).

## 1. Why `components/ui` is Important
Under the **shadcn/ui** project structure convention, reusable base UI components (like buttons, dialogs, inputs) are placed in the `@/components/ui` folder. This separate categorization allows:
- **Clean Separation**: Keeps simple presentation components (UI primitives) distinct from page-level layouts or domain-specific features.
- **CLI Compatibility**: The shadcn CLI automatically references this path to add, update, and manage base components (e.g. `npx shadcn@latest add button`).
- **Path Aliasing**: Keeps import statement paths clean and framework-agnostic using `@/components/ui/...` rather than relative paths.

---

## 2. Setting Up a New React/Next.js Project
If you want to migrate this application to React or start a new Next.js interface, initialize it with the following steps:

### Step 2.1: Initialize Next.js Project with TypeScript and Tailwind
Run the following command to create a Next.js application:
```bash
npx create-next-app@latest my-library-app --typescript --tailwind --eslint --src-dir --app --import-alias "@/*"
```
During creation, make sure to accept:
- **TypeScript**: Yes
- **Tailwind CSS**: Yes
- **src/ directory**: Yes (or No, depending on choice; if Yes, components are at `src/components`)
- **App Router**: Yes
- **Import alias**: `@/*`

### Step 2.2: Setup shadcn/ui
Navigate into your project folder and run the shadcn init tool:
```bash
cd my-library-app
npx shadcn@latest init
```
This CLI will prompt you for configuration details:
- **Style**: Default
- **Base Color**: Zinc / Neutral
- **CSS Variables**: Yes
- **Path for components**: `@/components` (this configures the default path for UI components as `@/components/ui`)
- **Path for utils**: `@/lib/utils`

## 3. Installing Dependencies for the Copied Components
To use the copied components in your React project, you must install the following npm dependencies:
```bash
npm install three @radix-ui/react-slot class-variance-authority clsx tailwind-merge
```
And if you want type safety for Three.js:
```bash
npm install -D @types/three
```

---

## 4. Path Aliasing & Utility Setup
Ensure that your `lib/utils.ts` exists and exports the `cn` helper (usually pre-generated by shadcn):
```typescript
// src/lib/utils.ts or lib/utils.ts
import { clsx, type ClassValue } from "clsx"
import { tailwindMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return tailwindMerge(clsx(inputs))
}
```
If you encounter module resolution issues, verify your `tsconfig.json` paths mapping:
```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```
